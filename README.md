# SmartVoiceLamp
基于 RISC-V 的智能语音灯控助手，集成语音控制、光感自适应、声纹安全锁、AI 对话等功能
项目简介
本作品为参赛作品，搭载BH1750光照传感器实现环境光自适应调光，集成PWM无级灯光控制、语音交互、声纹识别、DeepSeek大模型联网问答、播报音量开关、离线灯控闹钟等功能。
系统采用多线程Python架构，配套Tkinter全屏触控GUI，支持离线基础功能与联网AI问答双模式。

## 硬件清单
1. K1 RISC-V（Muse Pi Pro）开发板
2. BH1750 I2C环境光传感器
3. LED灯珠+220Ω限流电阻（GPIO71 PWM调光）
4. USB麦克风、USB扬声器
5. HDMI触控显示屏

## 核心功能
1. BH1750光感自适应调光：环境亮度越高，LED灯光自动降低亮度
2. 语音精准PWM调光：支持固定亮度、增减亮度语音指令
3. 声纹安全锁：声纹匹配度低于70%拒绝响应，防止误触发
4. DeepSeek大模型联网：天气查询、百科问答
5. 拓展功能：播报音量开关、倒计时闹钟、离线本地指令库（断网可用）
